# wiu

[Français](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · **Русский**

Программа для просмотра изображений в Windows x64, написанная на Rust. Позволяет просматривать фотографии без редактирования и изменения файлов.

## Использование

При работе с исходным кодом сначала соберите приложение и создайте папку `dist/`, как описано в разделе [Сборка](#сборка). Папки `target/` и `dist/` создаются локально и не отслеживаются Git.

Откройте `dist/wiu.exe`. Приложение запускается в развёрнутом окне со стандартной строкой заголовка Windows и диалогом выбора одного или нескольких изображений. При отмене выбора окно остаётся готовым к открытию изображения. Также поддерживается перетаскивание файлов. F11 включает полноэкранный режим; F11 или Esc позволяют выйти из него.

```powershell
.\dist\wiu.exe "C:\Photos\summer 2026.jpg"
.\dist\wiu.exe "C:\Photos\a.png" "C:\Photos\b.tiff"
```

| Сочетание клавиш | Действие |
| --- | --- |
| Ctrl+O | Выбрать изображения |
| Стрелки влево/вправо | Предыдущее/следующее изображение |
| Колесо мыши | Изменить масштаб относительно курсора |
| Перетаскивание левой кнопкой мыши | Переместить изображение |
| 0 / Adapter | Вписать в окно |
| 1 / 100 % | Исходный размер |
| F11 / Esc | Войти в полноэкранный режим/выйти из него |
| Пробел | Приостановить/возобновить GIF |

При открытии одного изображения можно просматривать совместимые изображения из той же папки, отсортированные по имени. При передаче нескольких путей просмотр ограничивается выбранными файлами. Для форматов, декодируемых библиотекой `image`, учитывается ориентация EXIF. Открытие файла никогда не изменяет его байты.

## Интеграция с Проводником Windows

Нажмите **Installer** в окне приложения или выполните:

```powershell
.\dist\wiu.exe --install
```

Это скопирует wiu в `%LOCALAPPDATA%\Programs\wiu\wiu.exe` и зарегистрирует приложение в меню **Открыть с помощью**, а также добавит действие **Ouvrir avec wiu** в контекстное меню для текущего пользователя. После успешной установки кнопка **Installer** исчезает. Если запустить другой исполняемый файл, содержимое которого отличается от установленной копии, появится кнопка **Mettre à jour**. После обновления она исчезает; если обе копии идентичны, кнопка установки не отображается. Перед обновлением закройте остальные окна wiu. В Windows 11 классическое действие может находиться в пункте **Показать дополнительные параметры**. Права администратора не требуются. Приложение по умолчанию для открытия изображений двойным щелчком пользователь по-прежнему выбирает в Windows.

Чтобы удалить эти записи, выполните `wiu.exe --uninstall`. Затем закройте wiu и при необходимости удалите папку установки. Установку можно повторять; чтобы заменить установленный исполняемый файл, сначала закройте эту копию и выполните установку из новой портативной версии.

## Форматы и ограничения

- JPEG/JPG/JFIF, PNG, BMP, TIFF, ICO, PNM/PPM/PGM/PBM и TGA: встроенные декодеры Rust.
- GIF: встроенный декодер Windows с поддержкой прозрачности, задержек кадров и способов восстановления кадров анимации.
- WebP и AVIF: только первый кадр, через доступные в Windows кодеки WIC. Могут потребоваться расширения изображений WebP/AV1 для Windows. При отсутствии кодека приложение выдаёт понятную ошибку. Поэтому поддержка этих двух форматов в Windows без соответствующих кодеков не гарантируется.
- SVG: встроенный рендеринг Direct2D в Windows 10/11, статическое изображение с размерами документа. Некоторые сложные возможности SVG (фильтры, скрипты, анимации) не поддерживаются Direct2D. Внешние ссылки запрещены.
- Многостраничный TIFF: только первая страница. ICO: вариант изображения выбирает декодер. HEIC и RAW не поддерживаются; расширенного управления цветовыми профилями/HDR нет.
- Максимальный размер файла — 128 МиБ. Объём декодированных пикселей или всех кадров GIF вместе ограничен 256 МиБ. Загрузка выполняется последовательно вне потока интерфейса; устаревшие запросы игнорируются.

## Сборка

Требуется стабильная версия Rust (не ниже 1.92 для интерфейса), целевая платформа `x86_64-pc-windows-gnu` и MinGW (`gcc`, `windres`) в PATH.

```powershell
cargo build --release --locked
cargo test --locked
```

Версии зависимостей зафиксированы в `Cargo.lock`. Если все зависимости уже есть в кэше, к командам Cargo можно добавить `--offline`. Интерфейс использует eframe/egui; диалоги, GIF и дополнительные кодеки используют Windows; для SVG применяется программный рендеринг Direct2D. Во время работы ничего не скачивается.

Исполняемый файл создаётся в `target/release/wiu.exe`. После сборки создайте папку дистрибутива с помощью Python:

```powershell
python tools/package.py
```

Скрипт копирует в `dist/` исполняемый файл, все пять языковых версий этой документации, лицензию проекта и лицензии зависимостей. Он использует `cargo metadata --offline`, поэтому зависимости должны уже находиться в кэше.

Проверка декодирования без открытия окна: `wiu.exe --check "image.png" "image.svg"` (код выхода 0, если все файлы доступны для чтения, иначе 1). Тесты создают образцы в `target/fixtures`.

Изменения реестра ограничены ключами `HKCU\Software\Classes\Applications\wiu.exe`, `HKCU\Software\Classes\wiu.Image`, действиями `wiu` в `SystemFileAssociations`, ключом `HKCU\Software\wiu` и значением `wiu` в `RegisteredApplications`.
